# Towelshop

Towelshop — mobilga mos PWA ilova. Texnologiyalar: React (Vite), Tailwind CSS, Firebase Auth, Firestore va React Leaflet.

## Ishga tushirish

1. `npm install`
2. `.env.example` faylidan nusxa olib `.env` yarating va Firebase qiymatlarini to'ldiring.
3. `npm run dev`

## Muhim jihatlar

- UI matnlari Uzbek (Lotin) tilida.
- Kirish: 9 xonali telefon raqami `telefon@towelshop.local` ko'rinishida emailga map qilinadi.
- Rollar: `admin`, `staff`, `barber`.
- PWA manifest `vite-plugin-pwa` orqali sozlangan.
- Rasm yuklash funksiyasi qo'shilmagan.
